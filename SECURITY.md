# Security Policy

## Supported versions

Only the latest release of Bitarr receives fixes.

## Reporting a vulnerability

Please do not report security problems in public issues.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Include the version, how to reproduce the problem and what an attacker could
do with it.

Bitarr is based on [qBittorrent](https://github.com/qbittorrent/qBittorrent). If the problem is in code
inherited from qBittorrent, it may also affect upstream, so it is worth reporting there as well.
